# Android端camera2相机app项目：

## 基本功能描述：多种机型上实现兼容的权限申请、预览、拍照、图库、图片查看器、设置功能

一共四个界面：
1. 相机预览界面
2. 设置界面
3. 图库界面
4. 图片查看器界面

## 功能与交互描述如下：

### 相机预览界面：
1. 切换前后摄像头，通过界面最底部的bottom bar中右侧的按钮切换相机前后摄
2，打开图库界面，通过界面最底部的bottom bar中左侧的缩略图按钮切换打开图库界面
3. 拍照，通过界面最底部的bottom bar中中间的按钮拍照
4. 切换不同的相机模式，通过界面中底部的mode bar(mode bar在bottom bar垂直方向上方)中两个按钮(普通、专业)切换不同的相机模式
5. 切换不同的焦段，如果后摄存在多个摄像头，通过中底部的focal bar(focal bar在mode bar垂直方向上方)中一栏多个焦段按钮切换不同后摄（例如超广0.6x、主摄1.0x、长焦2.0x）
6. 切换不同的预览、拍照图像数据的比例，通过界面最顶部的top bar中右侧的aspect bar中多个比例按钮切换，比例包括：短边:长边 = 1:1、3:4、9:16、全屏（full）一共4个比例，
7. 打开设置界面，通过界面顶部的top bar中左侧的设置按钮打开设置界面
8. 3A调整组件：普通模式下不可见；当切换到专业模式时，会显示界面的中底部3A bar(3A bar在focal bar垂直方向上方)的3A调整组件：对焦距离、曝光补偿、iso、快门、白平衡，一共5行,每行包括3A名称、A/M、滑块、3A值。
9. 相机预览显示view, 位于界面最底层，大小不影响其他ui元素的布局，调整预览比例时会同步计算调整相机预览显示view的大小（宽度不变，高度变化）。

### 图库界面：
1. 界面顶部的top bar左侧为返回按钮，点击返回相机预览界面
2. top bar下面为多张图片，3列n行的网格排布，默认打开设置的拍照图片保存位置，选择则打开图片查看器界面，使用图片查看器打开图片

### 图片查看器界面：
图片查看器界面：
1. 界面顶部的top bar左侧为返回按钮，点击图库界面
2. 显示图片的exif的格式化信息, 采用hud的方式来展示
3. exif bar垂直方向下方为图片显示区域，支持缩放图片

设置界面：
1. 界面顶部的top bar左侧为返回按钮，点击返回相机预览界面
2. 预览分辨率设置：下拉列表展示当前摄像头支持的预览分辨率列表，点击选择指定预览分辨率，预览界面会忽略当前预览比例，按照选择的预览分辨率显示
3. 拍照分辨率设置：下拉列表展示当前摄像头支持的拍照分辨率列表，点击选择指定拍照分辨率，拍照保存时会忽略当前拍照比例，按照选择的拍照分辨率保存
4. 拍照图片保存位置设置：点击浏览存储目录，选择拍照图片保存位置，默认为/storage/emulated/0/DCIM/Camera
5. 前摄镜像处理开关设置：点击开关前摄镜像处理功能，前摄镜像处理功能包括：前摄预览镜像显示与前摄拍照镜像保存，默认打开

### 补充说明：
1. 普通模式下，相机采用自动3A; 专业模式下可以通过3A调整组件调整3A参数
2. 相机预览界面、图库、图片查看器、设置界面之前正常跳转
3. 预览和拍照，所见即所得
4. 必要的相机、文件等权限申请
5. 默认预览采用小尺寸 + 拍照使用尺寸，举例：预览w*h = 1440*1080，拍照w*h = 4096*3072
6. 相机预览显示view的宽度一直等于屏幕的宽度，高度随预览比例进行调整。相机预览显示view采用绝对布局，在比例1：1和3：4时，view的顶部距离界面最上边缘的高度等于top bar的高度，这使得view紧贴top bar的下边缘；在比例9：16时，需要根据view的高度与屏幕高度，计算view的顶部距离界面最上边缘的高度使得view位于屏幕的手机竖屏下垂直方向的居中位置；在全屏时，view的尺寸为屏幕的尺寸，布局对齐屏幕。相机预览显示view的宽度为预览数据的短边，高度为预览数据的长边。
7. 只有在后摄时才能切换普通模式到专业模式，在前摄状态下无法切换普通模式到专业模式；专业模式状态下，无法切换前后摄，只能使用后摄
